# CodeAlpha Sentiment Analysis Project

## Project Overview
This project analyzes customer reviews using Natural Language Processing (NLP). It classifies reviews into Positive, Negative, and Neutral sentiments and identifies emotions using the NRC Emotion Lexicon.

## Objectives
- Analyze customer review text.
- Classify reviews into sentiment categories.
- Detect emotions in customer feedback.
- Visualize sentiment and emotion patterns.
- Understand customer opinions and feedback.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- VADER Sentiment Analyzer
- NRCLex (NRC Emotion Lexicon)
- Scikit-learn
- Jupyter Notebook

## Dataset Information
The project uses an Amazon customer reviews dataset.

**Dataset:** `Amazon_Reviews_Dataset.csv`

**Dataset Details:**
- 5000 reviews
- `review_text` – Customer review text
- `label` – Actual sentiment label

## Analysis Performed
1. Data Loading and Exploration
2. Sentiment Distribution Analysis
3. VADER Sentiment Classification
4. Model Accuracy Evaluation
5. Classification Report
6. Confusion Matrix
7. Emotion Detection using NRC Emotion Lexicon
8. Emotion Distribution Visualization
9. Sentiment Percentage Pie Chart
10. Final Results and Insights

## Project Files
- `CodeAlpha_SentimentAnalysis.ipynb` – Option 1 notebook.
- `CodeAlpha_Sentiment_Analysis_Option2.ipynb` – Option 2 notebook.
- `Amazon_Reviews_Dataset.csv` – Amazon reviews dataset.
- `CodeAlpha_Reviews_Dataset.csv` – Additional reviews dataset.
- `Option2_Sentiment_Analysis_Results.csv` – Sentiment analysis results.
- `Option2_Emotion_Distribution.csv` – Emotion distribution results.
- `visualizations/` – Saved visualization dashboard.
- `requirements.txt` – Required Python libraries.
- `README.md` – Project documentation.

## Conclusion
This project demonstrates sentiment classification and emotion detection using NLP techniques. VADER was used to classify customer reviews into Positive, Negative, and Neutral categories, while the NRC Emotion Lexicon was used to identify emotions such as Joy, Sadness, Anger, Fear, Trust, and Anticipation.

The results help understand customer opinions and can support marketing strategies and product development.
